## 0. 出题来源（聚焦一个算法点）

- 本地项目：`E:\project\RedStoneMusic-local`
- 远端仓库：<https://github.com/honghax/AutoRedStoneMusic>（本人推送）
- 算法点：**调度器的并发发声上限与事件取舍**。

项目里的时序调度器（`McMusicMaker/poc/07_build_scheduler.py`）会把一个音符展开成：

- 主击；
- 延音重击：时值超过 1.6 s 后每 10 刻重击一次，音量按 0.82 衰减；
- 混响 tap：每个击发在 +3 刻与 +8 刻各补一个更轻的采样。

然后它做一次并发自检：

```python
ring = 28
max_overlap = 0
for tk in ticks:
    max_overlap = max(max_overlap,
                      sum(len(bytick[t2]) for t2 in ticks if tk - ring < t2 <= tk))
...
print(f'MAX SIMULTANEOUS≈{max_overlap} (247 cap -> {"OK" if max_overlap<200 else "RISK"})')
```

也就是说：每个声音持续 `ring = 28` 刻，服务器最多混 247 个声音（项目把 ≥200 视为风险）。**原实现只检测峰值并警告，不会自动取舍**。

本题保留这个场景，把「检测」升级为「优化」：

> 在同时发声数不超过 $K$ 的前提下，丢掉一部分事件，使保留事件的总音量最大。

事件列表就是调度器展开后的结果（题面直接给出每个事件的开始时刻与音量），因此问题的核心是一个容量受限的带权区间选择。

---

## 1. 建模

每个事件 $i$ 是一个半开区间

$$
[t_i,\ t_i+28)
$$

权重为 $v_i$。要求选出一个子集，使任意时刻被选中区间覆盖的次数不超过 $K$，并最大化权重和。

这就是**带权区间选择 + 容量 $K$**：

- $K=1$：经典带权区间调度，按右端点排序 + DP / 二分；
- $K>1$：不能简单贪心，标准做法是最小费用流。

---

## 2. 最小费用流建模

把所有出现过的端点（每个 $t_i$ 与 $t_i+28$）排序去重，得到时刻节点 $0,1,\dots,M-1$。

建图：

1. **时间轴边**：$i\to i+1$，容量 $K$，费用 $0$；
2. **事件边**：$t_i$ 对应的节点 $\to t_i+28$ 对应的节点，容量 $1$，费用 $-v_i$；
3. 源点 $S=0$，汇点 $T=M-1$，发送 $K$ 单位流。

解释：

- 每一单位流代表「一个可用的同时发声槽位」；
- 时间轴边的容量 $K$ 表示任意时刻最多有 $K$ 个单位流通过，即最多 $K$ 个声音同时存在；
- 选择事件 $i$ 等价于让一单位流走它的边：占住区间 $[t_i,t_i+28)$ 的一个槽位，并获得收益 $v_i$（费用 $-v_i$）；
- 其余不选事件的流沿时间轴以费用 $0$ 通过。

于是

$$
\text{最大保留音量} = -\text{最小费用}.
$$

容量 $K$ 的流总能沿时间轴走完，所以发送 $K$ 单位一定可行。

---

## 3. 最小费用流实现

- 节点数 $M\le 2E$，边数约 $M+E$（含反向边约 $2(M+E)$）；
- 初始图是 DAG（时间边向前、事件边从 $t$ 指向 $t+28$），先按节点编号顺序求一次初始势能 $h$；
- 之后每轮用 **Dijkstra + 势能** 找最短增广路（约化费用非负），增广直到发送 $K$ 单位；
- 由于事件边容量为 $1$，每轮至少增广 $1$ 单位，至多 $K$ 轮。

复杂度：

$$
O\bigl(K\cdot (M+E)\log M\bigr),
$$

$E=10^5$、$K=20$ 时约几千万次操作。

---

## 4. 正确性

**引理 1（流分解）**：把 $K$ 单位 $S\to T$ 的流按路径分解，每条路径要么只走时间轴（空闲槽位），要么在某条事件边上走一次。若事件边 $i$ 被使用，则占用一个槽位贯穿 $[t_i,t_i+28)$。

**引理 2（容量等价）**：对任意时刻 $x$，横切时间轴（或任一事件区间的内部），通过的流不超过该切边的容量 $K$；而被选中的事件恰好在区间内部贡献 1 单位流。因此任意时刻的选中区间数 $\le K$。

**引理 3（最优性）**：任一满足并发上限的可行子集，都能构造一个费用为 $-\sum v_i$ 的 $K$ 单位流（选中的事件走事件边，其余走时间轴）；反之任一 $K$ 单位流也对应一个可行子集。故最小费用等于「最大保留音量」的相反数。

**引理 4（最小费用流正确）**：初始势能取 DAG 最短距离，之后每轮用非负约化费用跑 Dijkstra，逐轮增广得到最小费用流（标准 successive shortest path 结论）。

---

## 5. 复杂度与内存

- 时间：$O(K(M+E)\log M)$，其中 $M\le 2E$；
- 内存：邻接表约 $2(M+E)$ 条边、$M$ 个势能/距离，约 $10\sim20$ MB。

实测：$E=10^5$、$K=20$、随机时刻与音量，程序本体约 **0.37 s**。

## 7. 参考代码（C++17，已验证）

```cpp
// 0004 - 并发发声上限下的最优事件取舍（加权区间选择 + 容量 K）
// 参考项目：E:\project\RedStoneMusic-local（07_build_scheduler.py 的 ring=28 / max_overlap / 247 上限）
// 编译：g++ -O2 -std=c++17 -o solution solution.cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

struct MinCostFlow {
    struct Edge { int to, next, cap, cost; };
    int n;
    vector<int> head;
    vector<Edge> e;

    explicit MinCostFlow(int n_) : n(n_), head(n_, -1) { e.reserve(1 << 20); }

    void addEdge(int u, int v, int cap, int cost) {
        e.push_back({v, head[u], cap, cost});
        head[u] = (int)e.size() - 1;
        e.push_back({u, head[v], 0, -cost});
        head[v] = (int)e.size() - 1;
    }

    // {最大流, 最小费用}，最多发送 limit 单位；Dijkstra + 势能
    pair<int, ll> run(int s, int t, int limit) {
        const ll INF = (ll)4e18;
        vector<ll> h(n, INF), dist(n);
        vector<int> preE(n), preV(n);

        // 初始图是 DAG（时间边 i->i+1，事件边 start->end），按编号顺序求初始势能
        h[s] = 0;
        for (int u = 0; u < n; ++u) {
            if (h[u] == INF) continue;
            for (int ei = head[u]; ei != -1; ei = e[ei].next) {
                if (e[ei].cap <= 0) continue;
                int v = e[ei].to;
                ll nd = h[u] + e[ei].cost;
                if (nd < h[v]) h[v] = nd;
            }
        }
        for (int i = 0; i < n; ++i) if (h[i] == INF) h[i] = 0;

        int flow = 0;
        ll cost = 0;
        while (flow < limit) {
            fill(dist.begin(), dist.end(), INF);
            fill(preE.begin(), preE.end(), -1);
            fill(preV.begin(), preV.end(), -1);

            priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
            dist[s] = 0;
            pq.push({0, s});
            while (!pq.empty()) {
                auto [d, u] = pq.top();
                pq.pop();
                if (d != dist[u]) continue;
                for (int ei = head[u]; ei != -1; ei = e[ei].next) {
                    if (e[ei].cap <= 0) continue;
                    int v = e[ei].to;
                    ll nd = d + e[ei].cost + h[u] - h[v];
                    if (nd < dist[v]) {
                        dist[v] = nd;
                        preE[v] = ei;
                        preV[v] = u;
                        pq.push({nd, v});
                    }
                }
            }
            if (dist[t] == INF) break;

            for (int v = 0; v < n; ++v) if (dist[v] < INF) h[v] += dist[v];

            int aug = limit - flow;
            for (int v = t; v != s; v = preV[v]) aug = min(aug, e[preE[v]].cap);
            for (int v = t; v != s; v = preV[v]) {
                e[preE[v]].cap -= aug;
                e[preE[v] ^ 1].cap += aug;
            }
            flow += aug;
            cost += (ll)aug * (h[t] - h[s]);
        }
        return {flow, cost};
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    const int RING = 28;   // 声音持续 28 刻（项目调度器常量）

    int T;
    cin >> T;
    string out;
    while (T--) {
        int E, K;
        cin >> E >> K;

        vector<int> ts(E), vs(E);
        vector<int> coord;
        coord.reserve(2 * E);
        for (int i = 0; i < E; ++i) {
            cin >> ts[i] >> vs[i];
            coord.push_back(ts[i]);
            coord.push_back(ts[i] + RING);
        }
        sort(coord.begin(), coord.end());
        coord.erase(unique(coord.begin(), coord.end()), coord.end());

        const int M = (int)coord.size();
        const int S = 0, TT = M - 1;

        MinCostFlow mcf(M);
        // 时间轴：相邻时刻之间容量 K，费用 0
        for (int i = 0; i + 1 < M; ++i) mcf.addEdge(i, i + 1, K, 0);
        // 每个事件：占用 [t, t+28)，选它收益 v
        for (int i = 0; i < E; ++i) {
            int a = (int)(lower_bound(coord.begin(), coord.end(), ts[i]) - coord.begin());
            int b = (int)(lower_bound(coord.begin(), coord.end(), ts[i] + RING) - coord.begin());
            mcf.addEdge(a, b, 1, -vs[i]);
        }

        auto res = mcf.run(S, TT, K);
        out += to_string(-res.second);
        out.push_back('\n');
    }
    fputs(out.c_str(), stdout);
    return 0;
}
```
