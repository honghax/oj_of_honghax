# 0005 题解：语音克隆：随机流跳转

> 配套题面：[problems/0005.md](../problems/0005.md)
> 验证代码：[verify/0005/solution.cpp](../verify/0005/solution.cpp)、[verify/0005/brute.cpp](../verify/0005/brute.cpp)

## 0. 出题来源（聚焦一个算法点）

- 本地项目：`E:\project\musicclone\moss-tts-cpp`
- 远端仓库：<https://github.com/honghax/-MOSS-TTS-Nano-Cpp>（本人推送）
- 算法点：**NumPy 2.x PCG64 兼容随机流**。

项目为了保证 C++ 版与 Python 采样器逐位一致，在 `cpp/src/main.cpp` 里直接复刻了 NumPy 的 PCG64（`seed = 1234`）：

```cpp
// NumPy 2.x PCG64（default_rng(1234) 的 bit generator）兼容实现。
struct U128 { uint64_t lo; uint64_t hi; };
U128 pcg_state_{0xf69b873d9fe45409ULL, 0x160ad84006fe21eaULL};
static constexpr U128 pcg_inc_{0xd0f51ce6006e4325ULL, 0x50c8fb163c7cea4eULL};
static constexpr U128 pcg_mult_{0x4385df649fccf645ULL, 0x2360ed051fc65da4ULL};

float next_random_() {
    // numpy: pcg_setseq_128_xsl_rr_64_random_r 先 step 后 output
    uint64_t hi_temp;
    uint64_t plo = _umul128(pcg_state_.lo, pcg_mult_.lo, &hi_temp);
    uint64_t h1 = pcg_state_.hi * pcg_mult_.lo + pcg_state_.lo * pcg_mult_.hi;
    uint64_t ph = hi_temp + h1;
    pcg_state_ = pcg_add_({plo, ph}, pcg_inc_);
    uint64_t out = pcg_rotr_(pcg_state_.hi ^ pcg_state_.lo,
                             static_cast<unsigned>(pcg_state_.hi >> 58));
    double d = static_cast<double>(out >> 11) * (1.0 / 9007199254740992.0);
    return static_cast<float>(std::min(0.99999994, std::max(0.0, d)));
}
```

原实现是**顺序**取数。本题把它扩展成可定位的随机流：

> 流式合成/断点续合成时，直接求第 $K$ 次取数，不生成前面的 $K$ 个数。

这正是 PCG 系列 RNG 的标准能力——**跳转（jump-ahead）**，但需要自己完成 128 位仿射幂运算。

---

## 1. 建模

记一步步进为仿射映射

$$
A(x)=\text{MULT}\cdot x+\text{INC}\pmod{2^{128}}.
$$

第 $K$ 次取数（0-based）是

$$
\text{out}_K=\operatorname{out}\bigl(A^{K+1}(\text{state}_0)\bigr),
$$

其中 $\operatorname{out}(s)$ 是题目给出的旋转输出函数。

于是问题变成：**快速求仿射映射的 $K$ 次复合**。

---

## 2. 仿射复合与快速幂

把仿射映射记作二元组 $(a,c)$，表示 $x\mapsto a x+c$。先应用 $A=(a_1,c_1)$、再应用 $B=(a_2,c_2)$：

$$
B(A(x))=a_2a_1x+a_2c_1+c_2,
$$

所以复合为

$$
B\circ A=(a_2a_1,\ a_2c_1+c_2).
$$

对所有 $b=0,1,\dots,60$ 预处理

$$
P_b=A^{2^b},
\qquad P_{b+1}=P_b\circ P_b .
$$

对每个询问 $K$：

1. 令 `steps = K+1`；
2. 从恒等映射 $(1,0)$ 出发，对 `steps` 的每个为 1 的二进制位 $b$ 做 `res = res ∘ P_b`；
3. 计算 $\text{state}=a\cdot\text{state}_0+c$；
4. 取输出并右移 11 位。

因为 $P_b$ 都是同一个 $A$ 的幂，它们彼此可交换，按任意顺序复合结果相同。

---

## 3. 128 位乘法

只需要保留乘积的低 128 位。设

$$
a=a_1 2^{64}+a_0,\qquad b=b_1 2^{64}+b_0,
$$

则

$$
ab\bmod 2^{128}=a_0b_0+\bigl(a_1b_0+a_0b_1\bigr)2^{64}\pmod{2^{128}}.
$$

每个 $64\times64\to128$ 乘法再用四个 32 位部分积实现（代码中的 `mul64`）。这样不依赖编译器的 `__int128` 扩展，MSVC / MinGW / g++ 都能跑。

---

## 4. 正确性

**引理 1（仿射复合）**：如上定义的 $\circ$ 满足结合律，且 $(a,c)$ 作用于 $x$ 得到 $ax+c$；因此 $P_b$ 确实等于 $A^{2^b}$。

**引理 2（快速幂）**：把 `steps` 拆成二进制位后依次复合 $P_b$，得到的映射等于 $A^{\text{steps}}$。

**引理 3（取数位置）**：原实现先步进、后输出，所以第 $K$ 次取数对应 $K+1$ 次步进；$v=\text{out}\gg11$ 正是原代码中 `double` 的分子。

三者合起来即得答案。

---

## 5. 复杂度与内存

- 预处理 61 个仿射映射；
- 每个询问 $O(\log K)$ 次 128 位乘法（约 60 次），总计约 $6\times10^6$ 次；
- 内存 $O(1)$。

实测：$Q=10^5$、$K$ 随机取到 $10^{18}-1$，程序本体约 **0.96 s**。

## 7. 参考代码（C++17，已验证）

```cpp
// 0005 - PCG64 随机流的 O(log K) 跳转（128 位 LCG 仿射幂）
// 参考项目：E:\project\musicclone\moss-tts-cpp（main.cpp 的 next_random_ / NumPy PCG64 兼容实现）
// 编译：g++ -O2 -std=c++17 -o solution solution.cpp
#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;

struct U128 { ull lo, hi; };

// 64x64 -> 128
static inline void mul64(ull a, ull b, ull &lo, ull &hi) {
    ull a0 = a & 0xffffffffULL, a1 = a >> 32;
    ull b0 = b & 0xffffffffULL, b1 = b >> 32;
    ull p00 = a0 * b0, p01 = a0 * b1, p10 = a1 * b0, p11 = a1 * b1;
    ull mid = (p00 >> 32) + (p01 & 0xffffffffULL) + (p10 & 0xffffffffULL);
    lo = (mid << 32) | (p00 & 0xffffffffULL);
    hi = p11 + (p01 >> 32) + (p10 >> 32) + (mid >> 32);
}

// (a*b) mod 2^128
static inline U128 mul128(U128 a, U128 b) {
    ull lo, hi0, lo2, hi2, lo3, hi3;
    mul64(a.lo, b.lo, lo, hi0);
    mul64(a.hi, b.lo, lo2, hi2);   // 只取低 64 位，高 64 位溢出 128 位
    mul64(a.lo, b.hi, lo3, hi3);
    return {lo, hi0 + lo2 + lo3};
}

static inline U128 add128(U128 a, U128 b) {
    ull lo = a.lo + b.lo;
    ull hi = a.hi + b.hi + (lo < b.lo ? 1 : 0);
    return {lo, hi};
}

// 项目常量（NumPy default_rng(1234) 导出的 PCG64 状态）
static const U128 MULT = {0x4385df649fccf645ULL, 0x2360ed051fc65da4ULL};
static const U128 INC  = {0xd0f51ce6006e4325ULL, 0x50c8fb163c7cea4eULL};
static const U128 S0   = {0xf69b873d9fe45409ULL, 0x160ad84006fe21eaULL};

// 仿射映射 x -> a*x + c
struct Aff { U128 a, c; };

// 先应用 A 再应用 B
static inline Aff compose(const Aff &A, const Aff &B) {
    return {mul128(B.a, A.a), add128(mul128(B.a, A.c), B.c)};
}

// PCG64 XSL RR 64 输出
static inline ull output_of(U128 s) {
    ull x = s.hi ^ s.lo;
    unsigned r = (unsigned)(s.hi >> 58);
    if (r) x = (x >> r) | (x << (64 - r));
    return x;
}

static inline void appendUInt(string &out, ull v) {
    char buf[24];
    int n = 0;
    if (v == 0) buf[n++] = '0';
    while (v) { buf[n++] = char('0' + int(v % 10)); v /= 10; }
    while (n) out.push_back(buf[--n]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // powA[b] = A^(2^b)，A 为一步 LCG：x -> MULT*x + INC
    const int B = 62;
    vector<Aff> powA(B);
    powA[0] = {MULT, INC};
    for (int b = 1; b < B; ++b) powA[b] = compose(powA[b - 1], powA[b - 1]);

    int Q;
    cin >> Q;
    string out;
    out.reserve((size_t)Q * 18);
    for (int q = 0; q < Q; ++q) {
        ull K;
        cin >> K;
        ull steps = K + 1;   // 第 K 个输出是「先步进、后取输出」
        Aff res = {{1, 0}, {0, 0}};
        for (int b = 0; b < B; ++b)
            if ((steps >> b) & 1) res = compose(res, powA[b]);
        U128 state = add128(mul128(res.a, S0), res.c);
        ull val = output_of(state) >> 11;   // 53 位随机数，即项目里 double 的分子
        appendUInt(out, val);
        out.push_back('\n');
    }
    fputs(out.c_str(), stdout);
    return 0;
}
```
