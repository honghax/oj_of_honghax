# 0002 题解：湘北水文图：精确岸距场

> 配套题面：[problems/0002.md](../problems/0002.md)
> 验证代码：[verify/0002/solution.cpp](../verify/0002/solution.cpp)、[verify/0002/brute.cpp](../verify/0002/brute.cpp)

## 0. 出题来源（聚焦一个算法点）

- 本地项目：`E:\project\1945\war3d`（1945 抗战战略地图的三维渲染演示）
- 远端仓库：<https://github.com/honghax/1945.9.3>（本人推送）
- 算法点：**水系掩码 → 到岸距离场 → 水面深度着色**。

项目的 README 明确写了这条数据链：

> "Rivers, Dongting Lake and the Xiangjiang take their outlines from the ESRI World_Topo_Map water layer (2048² mask) ... **a distance-to-shore field drives the depth shading**."

`water.cpp` 中的 `LoadDepth()` 读取预计算好的 2048² `water_depth.bin`，`DepthAt(u,v)` 再对它做双线性采样。也就是说，**到岸距离场的精确计算是这条管线的前置步骤**：项目仓库里保存的是结果，本题把这一步单独拿出来，要求在海量格子上精确算出它。

为什么定 10 星 / 专家：精确的加权欧氏距离变换（EDT）属于专家级技术；四邻域 BFS、八邻域 BFS、倒角距离都会给出错误答案。再叠加非方形像元（$DX\ne DY$）、最近格并列规则、$6.25\times10^6$ 个格子和 $10^5$ 次询问，实现细节也很容易翻车。

---

## 1. 建模

记 $A=DX^2$、$B=DY^2$。对查询 $(r,c)$ 和陆地格 $(x,y)$：

$$
d^2=A\,(c-y)^2+B\,(r-x)^2 .
$$

它是**可分离**的：

$$
d^2=\underbrace{B(r-x)^2}_{\text{纵向}}+\underbrace{A(c-y)^2}_{\text{横向}} .
$$

因此可以：

1. **横向一遍**：对每一行，求每个列位置到「本行最近岸格」的横向代价；
2. **纵向一遍**：对每一列，把行代价加上纵向二次项，取最小。

两遍都是一维问题：

$$
F(x)=\min_{q}\bigl(f[q]+K(x-q)^2\bigr),
$$

其中 $K$ 是常数（横向 $A$、纵向 $B$），$f[q]$ 是已知代价。所有抛物线**二次项系数相同**，因此可以用经典的**下包络**（parabola lower envelope）在 $O(n)$ 内求出全部 $x$ 的 $F(x)$。

---

## 2. 一维下包络与并列规则

对两个中心 $p<q$：

$$
f[p]+K(x-p)^2=f[q]+K(x-q)^2
\iff x=\frac{(f[q]+Kq^2)-(f[p]+Kp^2)}{2K(q-p)} .
$$

令

$$
s=\left\lfloor \frac{(f[q]+Kq^2)-(f[p]+Kp^2)}{2K(q-p)}\right\rfloor .
$$

在整数 $x\le s$ 上 $p$ 不劣于 $q$；$x>s$ 上 $q$ 严格更优。维护一个栈 `v[]`（包络上的中心）与切换点 `z[]`：`z[k]` 是“上一个中心还赢”的最后一个 $x$。若新抛物线的 $s\le z[k]$，说明栈顶中心永远不会成为最优，弹掉；否则压栈。

求值时从左到右扫描 $x$，保持 `z[k+1] < x` 时前进，取 `v[k]`。

**并列规则**：上面对切换点使用 `floor`，并且 `z[k]` 表示“旧中心还赢”的最后位置，因此当两个抛物线在整数点完全相等时，**更小的中心胜出**。这正好对应：

- 横向：并列取更小的列；
- 纵向：并列取更小的行。

---

## 3. 二维算法

### 3.1 横向

对每一行 $j$：

- 陆地格 $q$：$f[q]=0$；
- 水域格：$f[q]=+\infty$（不参与包络）。

做一次 $K=A$ 的一维变换，得到：

- `g[j][c]`：$(j,c)$ 到本行最近岸格的横向平方代价；
- `ac[j][c]`：取到该代价的最小列。

若本行没有陆地，则整行 `g=INF`、`ac` 无意义。

### 3.2 纵向

对每一列 $c$：

- 令 $f[j]=g[j][c]$（已经是横向代价）；
- 做一次 $K=B$ 的一维变换。

得到最终：

$$
d^2(r,c)=\min_{x}\bigl(g[x][c]+B(r-x)^2\bigr),
$$

并记录取到最小值的行 `art[c][r]`。

### 3.3 输出最近岸格

对查询 $(r,c)$：

- 行：`x = art[c][r]`；
- 列：`y = ac[x][c]`（最近行的行内最优列，横向变换已经算好）；
- 距离：`d2 = gt[c][r]`。

若 `d2=INF`，说明全图没有陆地，输出 `-1 -1 -1`。

> 实现上把 `g/ac` 转置成「列优先」再跑纵向，避免 $6.25\times10^6$ 个格子上的跨行跳访。

---

## 4. 正确性

**引理 1（可分离）**：$d^2$ 的横向项只依赖 $c,y$，纵向项只依赖 $r,x$，故先对行取横向最小、再对列取纵向最小，等于对全部陆地格取二维最小。

**引理 2（一维包络）**：所有抛物线二次项系数相同。两个抛物线的差是线性函数，只有一个交点，因此每个抛物线在最优集合中最多出现为一段连续区间；按中心递增维护切换点即可得到完整下包络，$O(n)$。

**引理 3（并列）**：切换点取 $\lfloor \cdot\rfloor$ 且“旧中心在切换点仍胜”，等价于在整数点上并列时取更小的中心。所以横向得到最小列，纵向得到最小行。

**引理 4（最近格）**：设全体最优陆地格中行最小者为 $x^*$。纵向变换在所有行中取最小，并列取小行，故必得 $x^*$。在该行内，横向变换取最小横向代价；若有多个列达到同一横向代价（左右对称），横向变换取更小列。于是输出的 $(x^*,y^*)$ 按「先行后列」字典序最小。

**引理 5（空图）**：所有 $f$ 均为 $+\infty$ 时，包络为空，所有 $d^2=+\infty$，输出哨兵。

---

## 5. 复杂度与内存

- 时间：横向 $O(WH)$，纵向 $O(WH)$，询问 $O(Q)$，总计 $O(WH+Q)$。
- 内存：主要是一张 64 位距离表（$2500^2\times8\approx50$ MB）与三张 `uint16` 的最优行列表（各约 $12.5$ MB），峰值约 $130$ MB，低于 256 MB。
- 本题实测：$2500\times2500$ 掩码 + $10^5$ 询问，程序本体约 **0.62 s**。

## 6. 验证记录

### 6.1 与独立暴力对拍

`brute.cpp` 对每个询问直接扫描全部陆地格，按题面规则取最小 $d^2$（并列取小行、再取小列）。随机生成 $400$ 组小图：

- $1\le W,H\le 25$；
- $1\le DX,DY\le 15$；
- 陆地概率从 $0$ 到 $1$（含全水、全陆、单岸格、单行、单列）；
- 每组 $30$ 个随机询问。

`solution` 与 `brute` 的输出**逐行完全一致**。

### 6.2 样例

题面样例（$5\times5$，$DX=2,DY=3$，两格陆地）输出与手工计算一致，包括三处并列：

```
0 1 4
0 1 148
0 1 40
0 1 4
0 1 9
0 1 0
```

### 6.3 边界

- 全水：所有询问输出 `-1 -1 -1`；
- 全陆：每个询问输出自己，$d^2=0$；
- 单岸格：所有询问都指向该格；
- $W=1$ 或 $H=1$：一维包络退化，输出与暴力一致；
- $DX=DY=10^4$、$W=H=2500$：最大 $d^2\approx1.25\times10^{15}$，未溢出。

### 6.4 性能

$2500\times2500$ 随机掩码（约 10% 陆地）+ $10^5$ 询问：

- 程序本体约 **0.62 s**；
- 峰值内存约 **130 MB**。

> 实现细节：本机 MinGW 下 `std::to_string` 生成 $4\times10^5$ 个数字耗时约 1.8 s，换成手写整数输出后降到毫秒级。这不是算法问题，但会直接决定能否卡进时限。

## 7. 参考代码（C++17，已验证）

```cpp
// 0002 - 加权精确欧氏距离变换（最近岸格 + 平方距离）
// 参考项目：E:\project\1945\war3d（水系掩码 -> 到岸距离场 -> 深度着色）
// 编译：g++ -O2 -std=c++17 -o solution solution.cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

static const ll INF = (ll)4e18;
static const ll ZMIN = LLONG_MIN / 4;
static const ll ZMAX = LLONG_MAX / 4;

// 数学意义下的 floor(a / b)，b > 0
static inline ll floorDiv(ll a, ll b) {
    ll q = a / b, r = a % b;
    if (r != 0 && r < 0) --q;
    return q;
}

// f[q]：把中心放在 q 的代价；A：二次项系数
// out[x] = min_q f[q] + A*(x-q)^2，arg[x] 为取到最小值的最小 q
struct Transform1D {
    vector<int> v, arg;
    vector<ll> z, f, out;

    void run(const vector<ll> &cost, ll A) {
        const int n = (int)cost.size();
        f = cost;
        out.assign(n, INF);
        arg.assign(n, -1);
        v.assign(n, 0);
        z.assign(n + 1, 0);

        int k = -1;
        for (int q = 0; q < n; ++q) {
            if (f[q] >= INF) continue;
            ll fq = f[q] + A * (ll)q * q;
            if (k < 0) {
                k = 0;
                v[0] = q;
                z[0] = ZMIN;
                z[1] = ZMAX;
                continue;
            }
            bool placed = false;
            while (k >= 0) {
                const int p = v[k];
                ll fp = f[p] + A * (ll)p * p;
                ll num = fq - fp;
                ll den = 2LL * A * (q - p);
                ll s = floorDiv(num, den);   // 最后一个「p 不劣于 q」的整数 x
                if (s <= z[k]) {
                    --k;
                } else {
                    ++k;
                    v[k] = q;
                    z[k] = s;
                    z[k + 1] = ZMAX;
                    placed = true;
                    break;
                }
            }
            if (!placed) {
                k = 0;
                v[0] = q;
                z[0] = ZMIN;
                z[1] = ZMAX;
            }
        }
        if (k < 0) return;

        k = 0;
        for (int x = 0; x < n; ++x) {
            while (z[k + 1] < x) ++k;
            const int q = v[k];
            out[x] = f[q] + A * (ll)(x - q) * (x - q);
            arg[x] = q;
        }
    }
};

static inline void appendInt(string &s, ll v) {
    char buf[24];
    int n = 0;
    if (v == 0) buf[n++] = '0';
    while (v > 0) { buf[n++] = char('0' + (int)(v % 10)); v /= 10; }
    while (n > 0) s.push_back(buf[--n]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int W, H, DX, DY;
    if (!(cin >> W >> H >> DX >> DY)) return 0;

    vector<string> mask(H);
    for (int i = 0; i < H; ++i) cin >> mask[i];

    const ll A = (ll)DX * DX;
    const ll B = (ll)DY * DY;

    vector<ll> g((size_t)W * H, INF);
    vector<unsigned short> ac((size_t)W * H, 0);   // 行内最优列

    Transform1D tr;

    // 行变换：对每一行，求每个列位置到本行最近岸格的横向代价
    vector<ll> rowCost(W);
    for (int j = 0; j < H; ++j) {
        for (int x = 0; x < W; ++x) rowCost[x] = (mask[j][x] == '1') ? INF : 0;
        tr.run(rowCost, A);
        for (int x = 0; x < W; ++x) {
            const size_t id = (size_t)j * W + x;
            g[id] = tr.out[x];
            ac[id] = (unsigned short)(tr.arg[x] < 0 ? 0 : tr.arg[x]);
        }
    }

    // 转置，使列变换也变成连续访问（大图上显著更快）
    vector<ll> gt((size_t)H * W);
    vector<unsigned short> act((size_t)H * W);
    for (int j = 0; j < H; ++j)
        for (int x = 0; x < W; ++x) {
            const size_t src = (size_t)j * W + x;
            const size_t dst = (size_t)x * H + j;
            gt[dst] = g[src];
            act[dst] = ac[src];
        }
    g.clear(); g.shrink_to_fit();
    ac.clear(); ac.shrink_to_fit();

    // 列变换：对每一列，把行代价加上纵向二次项，得到全平面精确距离
    vector<unsigned short> art((size_t)H * W, 0);   // 转置布局：列 c 的第 j 行
    vector<ll> colCost(H);
    for (int x = 0; x < W; ++x) {
        const size_t base = (size_t)x * H;
        for (int j = 0; j < H; ++j) colCost[j] = gt[base + j];
        tr.run(colCost, B);
        for (int j = 0; j < H; ++j) {
            gt[base + j] = tr.out[j];
            art[base + j] = (unsigned short)(tr.arg[j] < 0 ? 0 : tr.arg[j]);
        }
    }

    int Q;
    cin >> Q;
    vector<int> qr(Q), qc(Q);
    for (int q = 0; q < Q; ++q) cin >> qr[q] >> qc[q];
    string out;
    out.reserve((size_t)Q * 32);
    for (int q = 0; q < Q; ++q) {
        int r = qr[q], c = qc[q];
        const size_t id = (size_t)c * H + r;
        if (gt[id] >= INF / 2) {
            out += "-1 -1 -1\n";
        } else {
            const int nr = (int)art[id];
            const int nc = (int)act[(size_t)c * H + nr];   // 最近行的行内最优列
            appendInt(out, nr);
            out.push_back(' ');
            appendInt(out, nc);
            out.push_back(' ');
            appendInt(out, gt[id]);
            out.push_back('\n');
        }
    }
    fputs(out.c_str(), stdout);
    return 0;
}
```
