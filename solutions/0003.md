原实现（节选）：

```cpp
// 简单避让：与已放置的标签重叠时逐级上移，仍冲突则本帧不画，避免多层文字叠成一团
bool room = false;
for (int attempt = 0; attempt < 3; ++attempt) {
    bool hit = false;
    for (size_t k = 0; k + 3 < placed.size(); k += 4) {
        if (left < placed[k] + placed[k + 2] && left + tw > placed[k]
            && top < placed[k + 1] + placed[k + 3] && top + th > placed[k + 1]) {
            hit = true;
            break;
        }
    }
    if (!hit) { room = true; break; }
    top -= th + 5.f;
}
if (!room) return;
```

原实现每次与**全部**已放置标签比较，标签一多就是 $O(N^2)$。本题保留完全相同的避让语义，把规模拉到 $N=10^5$，要求用数据结构把「候选矩形是否与已放置标签重叠」压到亚线性。

---

## 1. 建模

把屏幕看成一个 $W\times H$ 的二维网格，每个已放置标签给它覆盖的单位格 $+1$。**覆盖计数** $c[x][y]$ 的含义是「有多少个已放置标签盖住这个格子」。

对候选矩形 $R=[x,x+w)\times[y,y+h)$：

$$
R \text{ 与某个已放置标签有正面积重叠}
\iff \sum_{(i,j)\in R} c[i][j] > 0 .
$$

原因：若交集内部非空，至少有一个单位格同时被候选矩形和某个已放置标签覆盖；反之亦然。边相接时交集面积为 $0$，不会覆盖任何公共单位格，恰好对应题目里的严格不等式。

于是问题变成：

- **矩形加**（放置标签：整块 $+1$）；
- **矩形和查询**（候选矩形覆盖计数是否 $>0$）。

坐标范围很小（$W,H\le1024$，$y$ 最低约 $-410$），用一个支持「矩形加 + 矩形和」的二维树状数组即可。

---

## 2. 二维树状数组：矩形加 + 矩形和

用二维差分 $D$，覆盖计数 $c$ 是 $D$ 的二维前缀和。对 $c$ 的矩形前缀和

$$
S(X,Y)=\sum_{i\le X}\sum_{j\le Y}c[i][j]
$$

展开可得

$$
S(X,Y)=XY\cdot B_1(X,Y)-Y\cdot B_2(X,Y)-X\cdot B_3(X,Y)+B_4(X,Y),
$$

其中 $B_1,B_2,B_3,B_4$ 分别是 $D$、$(x-1)D$、$(y-1)D$、$(x-1)(y-1)D$ 的二维前缀和。每次修改 $D$ 的一个点，同时更新这四个 BIT：

```cpp
b1 += v;  b2 += v*(x-1);  b3 += v*(y-1);  b4 += v*(x-1)*(y-1);
```

矩形加 $[x_1,x_2]\times[y_1,y_2]$ 就转化为差分上的四个点修改：

$$
(x_1,y_1,+v),\ (x_1,y_2+1,-v),\ (x_2+1,y_1,-v),\ (x_2+1,y_2+1,+v).
$$

矩形和用二维前缀和容斥：

$$
\mathrm{sum}(R)=S(x_2,y_2)-S(x_1-1,y_2)-S(x_2,y_1-1)+S(x_1-1,y_1-1).
$$

坐标处理：

- $x$ 方向：单位格 $[x,x+w)$ 对应 1-based 下标 $[x+1,x+w]$；
- $y$ 方向：最小可能值为 $-410$，统一加偏移 `YOFF=620` 后仍为正；标签最多上移两次，偏移足够。
- 树状数组下标上界取 $W+2$ 与 $H+\text{YOFF}+2$。

---

## 3. 模拟

按输入顺序处理每个标签：

1. 依次尝试 $y$、$y-(h+5)$、$y-2(h+5)$；
2. 对每个位置查询覆盖计数，若为 $0$ 则放置：矩形 $+1$，记录最终 $y$，跳出；
3. 三个位置都为 $>0$ 则输出 `0`。

语义与项目原实现逐条一致：

- 顺序处理、只看「此前已放置」的标签；
- 最多检查 3 个位置；
- 严格重叠（边相接不算）；
- 丢弃的标签不加入集合。

---

## 4. 正确性

**引理 1（覆盖计数判定）**：候选矩形与某个已放置标签有正面积重叠 $\iff$ 候选矩形内至少一个单位格被覆盖 $\iff$ 覆盖计数矩形和 $>0$。

**证明**：两个轴对齐矩形有正面积交集，则交集是一个非空开矩形，必包含某个单位格；反之，被公共覆盖的单位格属于两者交集。边/点相接时交集面积为 0，不含单位格。

**引理 2（二维 BIT 正确）**：差分点修改经四个加权 BIT 求和，得到的 $S(X,Y)$ 等于覆盖计数的二维前缀和；矩形和容斥给出候选矩形内的总覆盖数。

**引理 3（模拟正确）**：按输入顺序、按同样的三个候选位置、按同样的严格重叠规则检查，归纳可得每个标签的输出与项目原实现完全一致。

---

## 5. 复杂度与内存

- 每个标签最多 3 次矩形和查询 + 1 次矩形加，每次 $O(\log W\log H)$；
- 总时间 $O(N\log W\log H)$，$N=10^5$ 时为千万级操作；
- 内存：四个 `long long` 二维 BIT，规模约 $1028\times1648\approx1.69\times10^6$ 个单元，合计约 **54 MB**，低于 256 MB。

本题实测：$1024\times1024$ 屏幕、$10^5$ 个标签，程序本体约 **0.66 s**。

## 7. 参考代码（C++17，已验证）

```cpp
// 0003 - 屏幕空间标签避让（精确模拟 + 二维矩形加/矩形和）
// 参考项目：E:\project\1945\war3d（main.cpp DrawLabels 的“重叠则上移，三次仍冲突则丢弃”）
// 编译：g++ -O2 -std=c++17 -o solution solution.cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 二维树状数组：矩形加 + 矩形和（四个 BIT 的经典写法）
struct BIT2D {
    int nx, ny;
    vector<ll> b1, b2, b3, b4;

    BIT2D(int nx_, int ny_) : nx(nx_), ny(ny_) {
        const size_t n = (size_t)(nx + 2) * (ny + 2);
        b1.assign(n, 0);
        b2.assign(n, 0);
        b3.assign(n, 0);
        b4.assign(n, 0);
    }

    inline void addPoint(int x, int y, ll v) {
        const ll vx = v * (x - 1);
        const ll vy = v * (y - 1);
        const ll vxy = vx * (y - 1);
        for (int i = x; i <= nx; i += i & -i) {
            const size_t row = (size_t)i * (ny + 2);
            for (int j = y; j <= ny; j += j & -j) {
                const size_t id = row + j;
                b1[id] += v;
                b2[id] += vx;
                b3[id] += vy;
                b4[id] += vxy;
            }
        }
    }

    inline void addRect(int x1, int x2, int y1, int y2, ll v) {
        addPoint(x1, y1, v);
        addPoint(x1, y2 + 1, -v);
        addPoint(x2 + 1, y1, -v);
        addPoint(x2 + 1, y2 + 1, v);
    }

    inline ll prefix(int x, int y) const {
        ll s1 = 0, s2 = 0, s3 = 0, s4 = 0;
        for (int i = x; i > 0; i -= i & -i) {
            const size_t row = (size_t)i * (ny + 2);
            for (int j = y; j > 0; j -= j & -j) {
                const size_t id = row + j;
                s1 += b1[id];
                s2 += b2[id];
                s3 += b3[id];
                s4 += b4[id];
            }
        }
        return s1 * x * y - s2 * y - s3 * x + s4;
    }

    inline ll rectSum(int x1, int x2, int y1, int y2) const {
        return prefix(x2, y2) - prefix(x1 - 1, y2) - prefix(x2, y1 - 1)
               + prefix(x1 - 1, y1 - 1);
    }
};

static inline void appendInt(string &s, ll v) {
    char buf[24];
    int n = 0;
    if (v < 0) { s.push_back('-'); v = -v; }
    if (v == 0) buf[n++] = '0';
    while (v > 0) { buf[n++] = char('0' + (int)(v % 10)); v /= 10; }
    while (n > 0) s.push_back(buf[--n]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int W, H, N;
    if (!(cin >> W >> H >> N)) return 0;

    // 标签最多上移 2 次，每次 h+5；h <= 200 -> 上移不超过 410
    const int YOFF = 620;
    const int NX = W + 2;
    const int NY = H + YOFF + 2;
    BIT2D bit(NX, NY);

    string out;
    out.reserve((size_t)N * 12);

    for (int i = 0; i < N; ++i) {
        int x, y, w, h;
        cin >> x >> y >> w >> h;

        // 项目原逻辑：最多尝试 3 个位置（初始、上移一次、上移两次）
        bool placed = false;
        int fy = y;
        for (int attempt = 0; attempt < 3; ++attempt) {
            const int yy = y - attempt * (h + 5);
            const int x1 = x + 1;
            const int x2 = x + w;              // 半开区间 [x, x+w)
            const int y1 = yy + YOFF + 1;
            const int y2 = yy + h + YOFF;      // [yy, yy+h)
            // 严格相交：矩形内部有正面积重叠
            if (bit.rectSum(x1, x2, y1, y2) == 0) {
                bit.addRect(x1, x2, y1, y2, 1);
                fy = yy;
                placed = true;
                break;
            }
        }

        if (placed) {
            out += "1 ";
            appendInt(out, x);
            out.push_back(' ');
            appendInt(out, fy);
            out.push_back('\n');
        } else {
            out += "0\n";
        }
    }

    fputs(out.c_str(), stdout);
    return 0;
}
```
