# 0006 题解：跟拍相机：最少校准段

> 配套题面：[problems/0006.md](../problems/0006.md)
> 验证代码：[verify/0006/solution.cpp](../verify/0006/solution.cpp)、[verify/0006/brute.cpp](../verify/0006/brute.cpp)

## 0. 出题来源（聚焦一个算法点）

- 本地项目：`E:\project\RedStoneMusic-local`
- 远端仓库：<https://github.com/honghax/AutoRedStoneMusic>（本人推送）
- 算法点：**跟拍相机的轨迹压缩**。

`redpiano_core.py` 的 `cam_follow_plan()` 会：

1. 按脉冲到达时刻逐刻采样相机锚点（相邻 cell 间线性插值）；
2. 用 $\pm 16$ 刻移动平均平滑；
3. 压缩成固定 `CAM_WIN_GT = 8` 的窗口：每个窗口开头发一条绝对校准，窗口内每刻发一条恒定相对步进。

固定 8 刻是经验值，项目并不保证它是最优的。本题保留「绝对校准 + 段内恒定步进」的语义，去掉固定长度限制，问：

> 在每轴误差不超过 $E$ 的前提下，最少需要多少次绝对校准？

这等价于对二维轨迹做**带误差上界的折线分段**（minimum-link path / piecewise-linear approximation），是计算几何里一个不平凡的问题；直接贪心会错（题面给了反例提示）。

---

## 1. 建模

把每个校准段 $[s,e]$ 看成：起点 $(x_s,z_s)$ 精确，段内速度 $(v_x,v_z)$ 恒定。

对每个 $t\in(s,e]$，两个坐标分别给出约束：

$$
v_x\in\left[\frac{x_t-x_s-E}{t-s},\ \frac{x_t-x_s+E}{t-s}\right],
\qquad
v_z\in\left[\frac{z_t-z_s-E}{t-s},\ \frac{z_t-z_s+E}{t-s}\right].
$$

段可行 $\iff$ 两个方向的区间交集都非空。

记 `reach[s]` 为从 $s$ 出发可行的最远终点：

- 从 $s+1$ 开始逐个加入 $t$，维护 $v_x$ 的可行区间 $[L_x,U_x]$ 与 $v_z$ 的 $[L_z,U_z]$；
- 任一区间变空，则 `reach[s] = t-1`；
- 全部加入仍可行，则 `reach[s] = N`。

---

## 2. DP

$$
dp[0]=0,\qquad
dp[e]=1+\min\{\,dp[s]\ :\ 0\le s<e,\ \text{reach}[s]\ge e\,\}.
$$

$dp[e]$ 表示覆盖 $[0,e]$ 的最少段数。答案是 $dp[N]$。

**为什么不是贪心**：从 $s$ 尽量往后伸，可能落在一个「后续可达性很差」的点上；换一个稍早的段终点反而能让下一段走得更远。随机测试中贪心频繁给出比 DP 多 1 段的答案。

---

## 3. 精确比较

区间端点是分数。用

```cpp
struct Frac { long long num, den; };   // den > 0
bool less(a,b) { return (__int128)a.num*b.den < (__int128)b.num*a.den; }
```

做交叉相乘，避免浮点误差。$N\le3000$、坐标 $\le10^9$，交叉乘积远小于 `__int128` 上限。

> 本机 32 位 MinGW g++ 没有 `__int128`，验证时用 clang++ 23（64 位）；64 位 g++ 同样支持。

---

## 4. 正确性

**引理 1（段可行性）**：固定 $s$ 时，$v_x$ 的逐点约束都是闭区间，它们的交集仍是闭区间；$v_z$ 同理。两个交集都非空当且仅当存在一组 $(v_x,v_z)$ 使段内每刻两轴误差都不超过 $E$。

**引理 2（reach 正确）**：逐个加入 $t$ 时区间只收缩，第一次变空之前的最大 $t$ 就是可行终点；因此 `reach[s]` 是从 $s$ 出发能覆盖的最远时刻。

**引理 3（DP 最优）**：任何可行划分的最后一个段是 $[s,N]$，且 $s$ 满足 `reach[s]≥N`；去掉这一段后，$[0,s]$ 是一个可行划分。反之，任取 `reach[s]≥e` 的 $s$ 和 $[0,s]$ 的可行划分，接上 $[s,e]$ 就得到 $[0,e]$ 的可行划分。故转移枚举了全部可能，DP 给出最小段数。

---

## 5. 复杂度与内存

- 求所有 `reach[s]`：$O(N^2)$；
- DP：$O(N^2)$；
- 内存：$O(N)$。

实测 $N=3000$：约 **0.07 s**。

## 7. 参考代码（C++17，已验证）

```cpp
// 0006 - 跟拍相机：最少校准段（二维走廊 + 可达区间 DP）
// 参考项目：E:\project\RedStoneMusic-local（redpiano_core.py cam_follow_plan 的采样/压缩）
// 编译：g++ -O2 -std=c++17 -o solution solution.cpp
#include <cstdio>
#include <vector>
#include <algorithm>
using namespace std;
typedef long long ll;
typedef __int128 i128;

struct Frac { ll num, den; };   // den > 0

static inline bool fracLess(const Frac &a, const Frac &b) {
    return (i128)a.num * b.den < (i128)b.num * a.den;
}

struct AxisCorridor {
    bool hasLo = false, hasHi = false;
    Frac lo{}, hi{};

    // 加入约束：slope ∈ [(dx-E)/dt, (dx+E)/dt]
    bool add(ll dx, ll E, ll dt) {
        Frac a{dx - E, dt}, b{dx + E, dt};
        if (!hasLo || fracLess(lo, a)) { lo = a; hasLo = true; }
        if (!hasHi || fracLess(b, hi)) { hi = b; hasHi = true; }
        return !(hasLo && hasHi && fracLess(hi, lo));
    }
};

int main() {
    int N;
    ll E;
    if (scanf("%d %lld", &N, &E) != 2) return 0;
    vector<ll> x(N + 1), z(N + 1);
    for (int i = 0; i <= N; ++i) scanf("%lld %lld", &x[i], &z[i]);

    // reach[s] = 从 s 出发（位置精确）时，最远能覆盖到的 tick
    vector<int> reach(N + 1, N);
    for (int s = 0; s < N; ++s) {
        AxisCorridor cx, cz;
        bool ok = true;
        for (int t = s + 1; t <= N; ++t) {
            const ll dt = t - s;
            if (!cx.add(x[t] - x[s], E, dt) || !cz.add(z[t] - z[s], E, dt)) {
                reach[s] = t - 1;
                ok = false;
                break;
            }
        }
        if (ok) reach[s] = N;
    }

    const int INF = 1e9;
    vector<int> dp(N + 1, INF);
    dp[0] = 0;
    for (int e = 1; e <= N; ++e) {
        for (int s = 0; s < e; ++s) {
            if (reach[s] >= e && dp[s] + 1 < dp[e]) dp[e] = dp[s] + 1;
        }
    }
    printf("%d\n", dp[N]);
    return 0;
}
```
