项目 README 对水系的描述是：

`water.cpp` 里实际用了邻域加权平均 + 盒式模糊来得到平滑水位；本题提取这句话背后的**严格水文问题**：一个格子要让水流到地图边界，所需的最低水面高度是多少。它等价于「最小化路径最大高程」的单源最短路，也就是 GIS 里的 Priority-Flood。

---

## 1. 建模

把每个格子看成图上的点，四邻接；路径代价是路径上高程的最大值。

对格子 $v$，定义

$$
\ell(v)=\min_{\text{path } v\to \text{border}}\ \max_{u\in\text{path}} a_u .
$$

边界格子的 $\ell(v)=a_v$（一步就流出）。

这就是以边界为多源、边权为 $\max$ 的最短路。

---

## 2. 算法：Priority-Flood + 桶队列

从所有边界格子出发，初始水位为自身高程。按水位从小到大扩展：

- 取出当前水位 $l$ 的格子 $u$；
- 对每个邻居 $v$：
  $$
  nl=\max(l,\ a_v);
  $$
  若 $nl<\ell(v)$，更新 $\ell(v)=nl$，把 $v$ 放进桶 $nl$。

因为水位只与高程有关、范围是 $[0,\max a]$，用**桶队列**代替堆：

- `bucket[l]` 存水位为 $l$ 的格子；
- 从 $l=0$ 扫到 $\max a$；
- 桶内用下标遍历，允许边遍历边追加（同一层内的 BFS）；
- 弹出时若 `level[u] != l` 则跳过（过期条目）。

总代价 $O(WH+\max a)$，每个格子最多被四条边更新。

---

## 3. 正确性

**引理 1（边界）**：边界格子一步可流出，$\ell=a_v$，是最小可能值。

**引理 2（松弛正确）**：若已知 $u$ 的最优水位 $l$，则经过 $u$ 到 $v$ 的路径水位为 $\max(l,a_v)$；对所有入边取最小即为 $v$ 的最优值。

**引理 3（桶顺序）**：桶按水位递增处理，当前弹出的 $l$ 已是该格子的最终值；后续只会出现不小于 $l$ 的水位，不可能再改进。过期条目由 `level` 判定跳过。

归纳即得所有格子的 $\ell$ 正确。

---

## 4. 复杂度与内存

- 时间：$O(WH+\max a+Q)$；
- 内存：高程、水位、桶，约 $O(WH+\max a)$。

实测 $W=H=2500$（$6.25\times10^6$ 格）+ $Q=10^5$：约 **2.28 s**，内存约 100 MB。

## 6. 参考代码（C++17，已验证）

```cpp
// 0006 - 湘北水文：最低出溢面（Priority-Flood / 桶队列）
// 参考项目：E:\project\1945\war3d（水系水位求解：从掩码与 DEM 解出水面的思路）
// 编译：g++ -O2 -std=c++17 -o solution solution.cpp
#include <cstdio>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int W, H;
    if (scanf("%d %d", &W, &H) != 2) return 0;
    const int N = W * H;
    vector<int> a(N);
    int maxh = 0;
    for (int i = 0; i < N; ++i) { scanf("%d", &a[i]); maxh = max(maxh, a[i]); }

    const int INF = 1e9;
    vector<int> lvl(N, INF);
    vector<vector<int>> bucket(maxh + 1);

    auto is_border = [&](int r, int c) { return r == 0 || r == H - 1 || c == 0 || c == W - 1; };
    for (int r = 0; r < H; ++r)
        for (int c = 0; c < W; ++c)
            if (is_border(r, c)) {
                int id = r * W + c;
                lvl[id] = a[id];
                bucket[a[id]].push_back(id);
            }

    const int dr[4] = {-1, 1, 0, 0};
    const int dc[4] = {0, 0, -1, 1};
    for (int l = 0; l <= maxh; ++l) {
        for (size_t p = 0; p < bucket[l].size(); ++p) {
            int u = bucket[l][p];
            if (lvl[u] != l) continue;
            int r = u / W, c = u % W;
            for (int d = 0; d < 4; ++d) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= H || nc < 0 || nc >= W) continue;
                int v = nr * W + nc;
                int nl = max(l, a[v]);
                if (nl < lvl[v]) {
                    lvl[v] = nl;
                    bucket[nl].push_back(v);
                }
            }
        }
    }

    int Q;
    scanf("%d", &Q);
    while (Q--) {
        int r, c;
        scanf("%d %d", &r, &c);
        printf("%d\n", lvl[r * W + c]);
    }
    return 0;
}
```
