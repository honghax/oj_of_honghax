# 0001. 星核魔方：最短回响

> 内存限制：256MB｜时间限制：6000ms｜难度：10 星｜分层：专家
> 解决次数：0｜提交次数：0

## 题目描述

探险队在遗迹深处带回了 $T$ 枚「星核魔方」。每枚魔方都是 $2\times 2\times 2$ 的立方体，六个面各由 $4$ 个符文格组成。仪式会把魔方打乱，并用一串标准记号记录打乱过程。

标准姿态下六个面的颜色为：上 $U$ 白、下 $D$ 黄、前 $F$ 红、后 $B$ 橙、右 $R$ 蓝、左 $L$ 绿。转动记号采用标准魔方记号：

- `U` / `U2` / `U'` 分别表示把上层顺时针转 $90^\circ$ / $180^\circ$ / 逆时针转 $90^\circ$；
- `R`、`F`、`D`、`L`、`B` 同理；
- 这里的「顺时针」一律指**从该面外侧正对该面看**的顺时针方向。例如 `U` 会把 $URF$ 角块送到 $UFL$ 的位置。

当一枚魔方的**每个面的 $4$ 个符文格都同色**时，它就被视为复原。注意：$2\times 2$ 魔方没有固定的中心块，因此**整枚魔方在空间中的朝向不作要求**——六面各自同色即可。

对每枚被打乱的魔方，请求出：

1. 使其复原所需的最少转动次数 $L$；
2. 长度为 $L$ 的**不同转动序列**的个数（对 $998244353$ 取模）；
3. 所有长度为 $L$ 的复原序列中，**字典序最小**的那一个。

序列的字典序按如下记号顺序逐位比较：

$$
U < U2 < U' < R < R2 < R' < F < F2 < F' < D < D2 < D' < L < L2 < L' < B < B2 < B'
$$

## 输入格式

第一行一个整数 $T$，表示魔方的个数。

接下来 $T$ 行，每行描述一枚魔方：先是一个整数 $k$，表示打乱序列长度；随后 $k$ 个转动记号（用空格分隔）。$k=0$ 表示这枚魔方没有被转动。

## 输出格式

共 $T$ 行，每个魔方输出一行：

$$
L \quad cnt \quad s_1\ s_2\ \cdots\ s_L
$$

其中 $L$ 是最少转动次数，$cnt$ 是长度为 $L$ 的复原序列个数对 $998244353$ 取模的结果，$s_1\cdots s_L$ 是字典序最小的最优复原序列。

若 $L=0$，该行只输出 `0 1`（没有后续记号）。

## 样例输入

```
5
0
1 U
2 R L'
4 R U R' U'
17 U R B' R' L2 F U F D F2 U L B' U' R' U' F'
```

## 样例输出

```
0 1
1 2 U'
0 1
4 16 U R U' R'
11 73728 U R2 F2 U2 F R U R' U F' R2
```

## 样例说明

- 第 1 枚未被打乱，已经复原：$L=0$，空序列只有 $1$ 种。
- 第 2 枚只转了 `U`：用 `U'` 可复原；另外 `D'` 也能让它六面同色（两者相差一个整体旋转），所以共 $2$ 种最优解，字典序最小的是 `U'`。
- 第 3 枚打乱为 `R L'`：这恰好是把整个魔方绕 $x$ 轴转了一下，六面仍然各自同色，因此 $L=0$。
- 第 4 枚 `R U R' U'`：最少 $4$ 步，共 $16$ 种最优解，字典序最小的是 `U R U' R'`。
- 第 5 枚需要 $11$ 步，共 $73728$ 种最优解。

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $T$ | $1 \le T \le 10^4$ | 魔方个数 |
| $k$ | $0 \le k \le 30$ | 每枚魔方的打乱长度 |
| 记号 | 上述 $18$ 种之一 | 保证合法 |

## 提示

- $2\times 2\times 2$ 魔方的不同「位置」总数为

$$
\frac{8!\times 3^7}{24}=3\,674\,160
$$

  其中除以 $24$ 正是因为「整体旋转」被视为同一种复原状态。
- 单枚魔方的最优解长度不超过 $11$。
- 注意：**最少步数**和**最优解个数**在整体旋转下不变，但「字典序最小的最优解」会随整体旋转而改变——请对真实状态做还原，而不是对某个等价代表做还原。
- 本题的预计算量较大，建议在程序开始时一次性建好全状态表，再依次回答询问。
