# 0004. 红石乐谱：和声预算

> 内存限制：256MB｜时间限制：3000ms｜难度：10 星｜分层：专家
> 解决次数：0｜提交次数：0

## 题目描述

红石音乐机器把乐谱展开成一串**发声事件**：每个音符会产生主击、延音重击和混响 tap；每个事件在服务器里持续 $28$ 刻（1.4 秒的采样余响）。

服务器的混音器同一时刻最多混合 $K$ 个声音。超过上限时，后加入的声音会被截断或丢失，所以调度器必须提前决定**丢弃哪些事件**。

现在给出全部事件：第 $i$ 个事件在时刻 $t_i$ 开始发声，音量（权重）为 $v_i$，持续 $28$ 刻，即占用半开区间 $[t_i,\ t_i+28)$。

请你选出一个事件子集，使得：

1. 在任意整数时刻，正在发声的事件数不超过 $K$；
2. 被保留事件的总音量最大。

输出这个最大总音量。

## 输入格式

第一行一个整数 $T$，表示测试组数。

每组数据：

- 第一行两个整数 $E,K$；
- 接下来 $E$ 行，每行两个整数 $t_i,v_i$。

## 输出格式

每组输出一行一个整数，表示最大总音量。

## 样例输入

```
2
5 1
0 10
10 20
20 15
5 5
30 100
3 2
0 10
0 20
0 30
```

## 样例输出

```
110
50
```

## 样例说明

第一组 $K=1$，事件区间分别为：

$$
[0,28),\ [10,38),\ [20,48),\ [5,33),\ [30,58).
$$

保留 $[0,28)$ 与 $[30,58)$，总音量 $10+100=110$，且任意时刻最多 1 个声音。

第二组三个事件都从 $0$ 刻开始、完全重叠，$K=2$ 时只能保留其中音量最大的两个：$20+30=50$。

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $T$ | $1\le T\le 3$ | 测试组数 |
| $E$ | $1\le E\le 10^5$ | 事件数 |
| $\sum E$ | $\le 2\times10^5$ | 所有组事件总数 |
| $K$ | $1\le K\le 20$ | 同时发声上限 |
| $t_i$ | $0\le t_i\le 10^9$ | 开始时刻 |
| $v_i$ | $1\le v_i\le 1000$ | 音量 |

## 提示

- 每个事件占用的时长固定为 $28$，但起点各不相同。
- $K=1$ 时就是「带权区间调度」；$K>1$ 时不能简单贪心。
- $2^E$ 枚举不可行；可以把「同时最多 $K$ 个」看成时间轴上的容量 $K$，用最小费用流建模。
- 答案不超过 $2\times10^8$，但建议用 64 位整数输出。
