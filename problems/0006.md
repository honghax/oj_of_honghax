# 0006. 湘北水文：最低出溢面

> 内存限制：256MB｜时间限制：3000ms｜难度：10 星｜分层：专家
> 解决次数：0｜提交次数：0

## 题目描述

1945 战略地图的水面不是一张平面：项目从 DEM 与水域掩码出发，为每个格子解出它应有的水位，让河湖「落进山谷里」，而不是浮在地表。

把这件事抽象成最基础的水文问题：

给定一张 $W\times H$ 的整数高程图。水从某个格子出发，只能沿上下左右移动，最终要流到地图边界（边界之外视为已经流出）。一条路径的**出溢面**是路径上所有格子高程的最大值。一个格子的**最低出溢面**是所有「从它出发到边界」的路径中，出溢面的最小值。

请回答 $Q$ 个询问：每个格子的最低出溢面。

## 输入格式

第一行两个整数 $W,H$。

接下来 $H$ 行，每行 $W$ 个整数，表示高程。

接下来一行一个整数 $Q$。

接下来 $Q$ 行，每行两个整数 $r,c$（$0\le r<H$，$0\le c<W$）。

## 输出格式

共 $Q$ 行，每行一个整数：该格子的最低出溢面。

## 样例输入

```
5 5
0 0 0 0 0
0 5 5 5 0
0 5 1 5 0
0 5 5 5 0
0 0 0 0 0
5
0 0
1 1
2 2
2 0
1 2
```

## 样例输出

```
0
5
5
0
5
```

## 样例说明

中心 $(2,2)$ 高程为 1，但四周被高程 5 的环包住；要到边界必须先越过 5，所以最低出溢面是 5。边界格直接就是自身高程。

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $W,H$ | $1\le W,H\le 2500$ | 地图尺寸，$W\cdot H\le6.25\times10^6$ |
| 高程 | $0\le a_{r,c}\le 10^6$ | 整数 |
| $Q$ | $1\le Q\le 10^5$ | 询问数 |

## 提示

- 这是「最小化路径最大值的单源最短路」：从边界多源出发，向格子里扩展。
- 朴素堆 Dijkstra 可以过，但 $6.25\times10^6$ 个格子、$10^6$ 种高程更适合**桶队列**：按水位从小到大处理，总代价 $O(WH+\max a)$。
- 一个格子的水位只会下降，可以用 `level` 数组去重；桶里的过期条目直接跳过。
