# 0006. 跟拍相机：最少校准段

> 内存限制：256MB｜时间限制：2000ms｜难度：10 星｜分层：专家
> 解决次数：0｜提交次数：0

## 题目描述

红石音乐的「跟拍相机」会逐刻跟随脉冲前沿：脉冲到达第 $i$ 个 cell 的时刻，相机就该出现在对应锚点附近。

项目的实现把整条轨迹压成固定 8 刻的窗口：每个窗口开头发一条**绝对校准**（`tp` 到精确坐标），窗口内每刻发一条**相对步进**（`tp @s ~dx ~ ~dz`）。窗口长度固定为 8 是经验值；真正的需求是：

> 用尽量少的绝对校准，让相机在每一刻都落在目标点 $E$ 格以内。

给定 $N+1$ 个时刻 $t=0,1,\dots,N$ 的目标坐标 $(x_t,z_t)$，以及误差上限 $E$。

一个**校准段** $[s,e]$ 的规则是：

- 在时刻 $s$ 做一次绝对校准，相机精确出现在 $(x_s,z_s)$；
- 在段内选择一个**恒定的逐刻速度** $(v_x,v_z)$（可以是任意有理数）；
- 对每个 $t\in[s,e]$，相机位置为
  $$
  (x_s+v_x(t-s),\ z_s+v_z(t-s)),
  $$
  并要求
  $$
  |x_s+v_x(t-s)-x_t|\le E,\qquad
  |z_s+v_z(t-s)-z_t|\le E .
  $$
- 段与段在端点处共享时刻：上一段在 $e$ 结束，下一段在 $e$ 做新的绝对校准，速度可以突变。

请把这 $N+1$ 个时刻划分成若干校准段，使段数（也就是绝对校准次数）最少。

## 输入格式

第一行两个整数 $N,E$。

接下来 $N+1$ 行，每行两个整数 $x_t,z_t$（$t=0..N$）。

## 输出格式

一行一个整数：最少的校准段数。

## 样例输入

```
4 0
0 0
1 0
2 0
2 1
2 2
```

## 样例输出

```
2
```

## 样例说明

轨迹先沿 $x$ 走、再沿 $z$ 走：

- 段 $[0,2]$：速度 $(1,0)$，精确覆盖 $(0,0),(1,0),(2,0)$；
- 段 $[2,4]$：在 $(2,0)$ 重新校准，速度 $(0,1)$，覆盖 $(2,1),(2,2)$。

两段即可，答案 2。

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $N$ | $1\le N\le 3000$ | 时刻数（共 $N+1$ 个点） |
| $E$ | $0\le E\le 10^9$ | 每轴允许误差 |
| $x_t,z_t$ | $\lvert x_t\rvert,\lvert z_t\rvert\le 10^9$ | 目标坐标 |

## 提示

- 固定段起点 $s$ 时，每个后续点 $t$ 对 $v_x$ 给出一个斜率区间
  $$
  \left[\frac{x_t-x_s-E}{t-s},\ \frac{x_t-x_s+E}{t-s}\right],
  $$
  $v_z$ 同理。段可行 $\iff$ 两个交叠区间都非空。
- 对每个 $s$ 求出「最远能覆盖到哪个 $t$」，再做一遍 DP：
  $$
  dp[e]=1+\min\{\,dp[s]\ :\ \text{reach}[s]\ge e\,\}.
  $$
- 直接贪心（能伸多长伸多长）不是最优，样例之外请自行构造反例；必须用 DP。
- 区间端点是分数，用交叉相乘比较；建议 64 位整数 + `__int128`（64 位 g++/clang 支持）。
