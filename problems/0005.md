# 0005. 语音克隆：随机流跳转

> 内存限制：256MB｜时间限制：3000ms｜难度：9 星｜分层：困难
> 解决次数：0｜提交次数：0

## 题目描述

MOSS-TTS-Nano 的 C++ 实现为了保证与 Python 采样器**逐位对齐**，直接复刻了 NumPy 2.x 的 PCG64 随机数发生器（固定 `seed = 1234`）。

它的一次取数是（所有运算均为 128 位无符号整数，模 $2^{128}$）：

1. **步进**：

$$
\text{state} \leftarrow \text{state}\times \text{MULT}+\text{INC};
$$

2. **输出**：把 `state` 写成高 64 位 $hi$ 与低 64 位 $lo$，

$$
\text{out}=\operatorname{rotr64}\bigl(hi\oplus lo,\ hi\gg 58\bigr),
$$

其中 $\operatorname{rotr64}(x,r)$ 表示把 64 位数 $x$ 循环右移 $r$ 位。

3. 采样器最终使用的均匀随机数分子为

$$
v=\text{out}\gg 11 \qquad (0\le v<2^{53}).
$$

在流式合成或断点续合成时，程序需要**直接定位到第 $K$ 次取数**，而不能从头生成前面所有随机数。

给定常量：

$$
\begin{aligned}
\text{state}_0&=\texttt{0x160ad84006fe21ea\_f69b873d9fe45409},\\
\text{INC}&=\texttt{0x50c8fb163c7cea4e\_d0f51ce6006e4325},\\
\text{MULT}&=\texttt{0x2360ed051fc65da4\_4385df649fccf645},
\end{aligned}
$$

下划线前为高 64 位，后为低 64 位。请回答 $Q$ 个询问：第 $K$ 次取数（从 $0$ 开始计数）的 $v$ 是多少。

## 输入格式

第一行一个整数 $Q$。

接下来 $Q$ 行，每行一个整数 $K$（$0\le K<10^{18}$）。

## 输出格式

共 $Q$ 行，每行一个整数，表示第 $K$ 次取数的 $v$。

## 样例输入

```
6
0
1
9
10
1000000000000
999999999999999999
```

## 样例输出

```
8797329410709207
3424498741124405
2374746320579233
3972230013896603
5374757454995707
6696823607146564
```

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $Q$ | $1\le Q\le 10^5$ | 询问数 |
| $K$ | $0\le K<10^{18}$ | 第几次取数（0-based） |

## 提示

- 第 $K$ 次取数对应「从 $\text{state}_0$ 出发步进 $K+1$ 次，再取输出」。
- 步进是一个**仿射映射** $x\mapsto \text{MULT}\cdot x+\text{INC}$，它的 $K$ 次复合可以像快速幂一样在 $O(\log K)$ 内求出。
- 128 位乘法可以直接用 64 位 g++/clang 的 `unsigned __int128`（只保留低 128 位）；原项目的 MSVC 没有这个类型，所以项目里是手写的 64 位分肢乘法。两种写法都允许。
- 直接循环 $K$ 次在 $K=10^{18}$ 时不可行。
