# 0005. 语音克隆：NumPy 随机流复刻

> 内存限制：256MB｜时间限制：2000ms｜难度：10 星｜分层：专家
> 解决次数：0｜提交次数：0

## 题目描述

MOSS-TTS-Nano 的 C++ 实现要求与 Python 采样器**逐位对齐**。Python 侧用的是

```python
numpy.random.default_rng(seed)   # bit generator = PCG64
```

它先由 `SeedSequence(seed)` 把任意整数种子混成 PCG64 的初始状态，再逐次输出 64 位随机数。项目里为了固定 `seed=1234`，把混好的 state/inc 直接写死；本题要求把**任意种子**的完整链路复刻出来，并支持直接跳到第 $K$ 次取数。

### SeedSequence(seed)

常量：

$$
\begin{aligned}
\text{INIT\_A}&=\texttt{0x43b0d7e5},&
\text{MULT\_A}&=\texttt{0x931e8875},\\
\text{INIT\_B}&=\texttt{0x8b51f9dd},&
\text{MULT\_B}&=\texttt{0x58f38ded},\\
\text{MIX\_MULT\_L}&=\texttt{0xca01f9dd},&
\text{MIX\_MULT\_R}&=\texttt{0x4973f715}.
\end{aligned}
$$

所有 32 位运算均按无符号回绕。两个辅助函数：

```c
uint32_t hashmix(uint32_t v, uint32_t *hc) {
    v ^= *hc;
    *hc *= MULT_A;
    v *= *hc;
    v ^= v >> 16;
    return v;
}
uint32_t mix(uint32_t x, uint32_t y) {
    uint32_t r = MIX_MULT_L * x - MIX_MULT_R * y;
    r ^= r >> 16;
    return r;
}
```

把 seed 拆成 32 位小端字（seed=0 时为 `[0]`），记作 `ent[]`，长度 `m`。取 `pool[4]`：

1. `hc = INIT_A`；
2. 对 `i=0..3`：`pool[i] = hashmix(i<m ? ent[i] : 0, &hc)`；
3. 对 `src=0..3`、`dst=0..3`、`src!=dst`：`pool[dst] = mix(pool[dst], hashmix(pool[src], &hc))`；
4. 对 `src=4..m-1`、`dst=0..3`：`pool[dst] = mix(pool[dst], hashmix(ent[src], &hc))`。

生成 8 个 32 位字：

```c
hc = INIT_B;
for (i = 0; i < 8; ++i) {
    uint32_t v = pool[i & 3];
    v ^= hc; hc *= MULT_B; v *= hc; v ^= v >> 16;
    words[i] = v;
}
```

按小端两两拼成 4 个 64 位字 `val[0..3]`：

```c
val[j] = words[2j] | ((uint64_t)words[2j+1] << 32);
initstate = ((uint128)val[0] << 64) | val[1];
initseq   = ((uint128)val[2] << 64) | val[3];
```

### PCG64 初始化与取数

记 128 位乘法与加法均模 $2^{128}$，乘法常量为

$$
\text{MULT}=\texttt{0x2360ed051fc65da4\_4385df649fccf645}.
$$

初始化：

$$
\text{INC}=(\text{initseq}\ll 1)\mid 1,
$$

$$
\text{state}=0;\quad
\text{state}=\text{state}\cdot\text{MULT}+\text{INC};\quad
\text{state}=\text{state}+\text{initstate};\quad
\text{state}=\text{state}\cdot\text{MULT}+\text{INC}.
$$

此后每次取数：

1. `state = state * MULT + INC`；
2. 令 $hi$、$lo$ 为 state 的高/低 64 位，
   $$
   out=\operatorname{rotr64}(hi\oplus lo,\ hi\gg58).
   $$

第 $K$ 次取数（0-based）就是**从初始 state 出发步进 $K+1$ 次**后的 $out$。

## 输入格式

第一行一个整数 $Q$。

接下来 $Q$ 行，每行两个整数 `seed K`（$0\le seed<2^{64}$，$0\le K<10^{18}$）。

## 输出格式

共 $Q$ 行，每行一个整数：第 $K$ 次取数的 $out\gg 11$（即项目里 double 的 53 位分子）。

## 样例输入

```
6
1234 0
1234 9
42 1000
42 1000000000000
0 999999999999999999
4294967295 1000000
```

## 样例输出

```
8797329410709207
2374746320579233
559014766975397
796593132872027
8298669528557071
2232470811943771
```

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $Q$ | $1\le Q\le 10^5$ | 询问数 |
| $seed$ | $0\le seed<2^{64}$ | NumPy 种子 |
| $K$ | $0\le K<10^{18}$ | 第几次取数（0-based） |

## 提示

- 先实现 SeedSequence（32 位混洗），再实现 PCG64 的 128 位步进；两部分都必须逐位复刻。
- 第 $K$ 次取数对应 $K+1$ 次 LCG 步进；仿射映射可以像快速幂一样在 $O(\log K)$ 内复合。
- 64 位 g++/clang 可直接用 `unsigned __int128` 做 128 位乘法；没有该扩展时可用 64 位分肢乘法。
- 直接顺序生成 $K$ 次在 $K=10^{18}$ 时不可行。
