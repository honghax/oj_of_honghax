# 0003. 战略地图：标签避让

> 内存限制：256MB｜时间限制：3000ms｜难度：9 星｜分层：困难
> 解决次数：0｜提交次数：0

## 题目描述

1945 战略地图上会绘制大量标签：地名、战役名、当前事件、行军单位名……它们按固定顺序提交给渲染器，每个标签在屏幕上先有一个「理想矩形」位置。

渲染器只做一件事：**重叠就往上挪，挪三次还不行就这一帧不画**。具体规则如下（与项目实现一致）：

1. 标签按输入顺序依次处理；
2. 对第 $i$ 个标签，矩形为 $(x,\ y,\ w,\ h)$，表示半开区域 $[x,x+w)\times[y,y+h)$；
3. 依次尝试三个位置：
   $$
   y_0=y,\qquad y_1=y-(h+5),\qquad y_2=y-2(h+5).
   $$
4. 在某个位置，如果它与**此前已经放置**的任意标签矩形都有正面积重叠，就换下一个位置；否则放在这里，并加入「已放置」集合；
5. 三个位置都与已放置标签重叠，则丢弃该标签（不加入集合）。

两个矩形「有正面积重叠」指它们的交集内部非空；**仅仅边或点相接不算重叠**。标签可以移动到屏幕上方（$y$ 变为负数），这不影响判定。

请按顺序输出每个标签的最终结果。

## 输入格式

第一行三个整数 $W,H,N$，分别表示屏幕宽、高和标签数量。

接下来 $N$ 行，每行四个整数 $x,y,w,h$，描述一个标签的理想矩形：

- $0\le x$ 且 $x+w\le W$；
- $0\le y$ 且 $y+h\le H$；
- $1\le w,h\le 200$。

## 输出格式

共 $N$ 行，按输入顺序：

- 若标签被放置：输出 `1 x y`，其中 $(x,y)$ 是它最终左上角（$y$ 可能为负）；
- 若标签被丢弃：输出 `0`。

## 样例输入

```
10 10 6
0 0 5 3
1 0 5 3
2 0 5 3
3 0 5 3
3 0 5 3
4 0 5 3
```

## 样例输出

```
1 0 0
1 1 -8
1 2 -16
0
0
0
```

## 样例说明

- 第 1 个标签放在 $(0,0)$。
- 第 2 个在 $(1,0)$ 与第 1 个重叠；上移 $h+5=8$ 后到 $(1,-8)$，可以放置。
- 第 3 个在 $(2,-8)$ 与第 2 个重叠；再上移到 $(2,-16)$，可以放置。
- 第 4 个的三个候选位置 $(3,0)$、$(3,-8)$、$(3,-16)$ 都重叠，丢弃。
- 第 5、6 个同样丢弃。

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $W,H$ | $1\le W,H\le 1024$ | 屏幕尺寸 |
| $N$ | $1\le N\le 10^5$ | 标签数量 |
| $w,h$ | $1\le w,h\le 200$ | 标签尺寸 |

## 提示

- 朴素做法是每次与所有已放置标签比较，$O(N^2)$ 在 $10^5$ 下不可行。
- 屏幕只有 $1024\times1024$，可以把它看成一个二维网格：一个标签覆盖若干单位格。某个候选矩形是否与已放置标签重叠，等价于它覆盖的格子中是否存在被覆盖过的格子。
- 注意「边相接不算重叠」，因此矩形按半开区间处理。
- 标签最多上移两次（第三次检查失败即丢弃），$y$ 的最小值不小于 $-2(h+5)\ge -410$。
