# 0002. 湘北水文图：精确岸距场

> 内存限制：256MB｜时间限制：3000ms｜难度：10 星｜分层：专家
> 解决次数：0｜提交次数：0

## 题目描述

1945 年的湘北战略地图上，洞庭湖与湘江被画成一片连续水面。为了让水面的颜色随「离岸远近」渐变，渲染器需要一张**到岸距离场**：对每个水域格子，找出离它最近的陆地格子，并记录精确的平方距离。

地图采用等距投影，横向与纵向的格子对应的实际长度并不相同：横向每格 $DX$ 米，纵向每格 $DY$ 米。格子 $(r,c)$ 与 $(x,y)$ 之间的平方距离定义为

$$
d^2(r,c \to x,y)=\bigl(DY\cdot(r-x)\bigr)^2+\bigl(DX\cdot(c-y)\bigr)^2 .
$$

给定一张 $W\times H$ 的水域掩码（`1` 表示水域，`0` 表示陆地）与 $Q$ 次询问。对每个询问格子 $(r,c)$，输出：

1. 离它最近的陆地格子 $(x,y)$；
2. 平方距离 $d^2$。

若使 $d^2$ 最小的陆地格子不唯一，取 $x$ 最小者；若仍有并列，取 $y$ 最小者。若整张图没有任何陆地格子，输出 `-1 -1 -1`。

询问格子本身也可以是陆地：此时最近陆地就是它自己，输出 `r c 0`。

## 输入格式

第一行四个整数 $W,H,DX,DY$。

接下来 $H$ 行，每行一个长度为 $W$ 的 `01` 串，描述一行格子。

接下来一行一个整数 $Q$。

接下来 $Q$ 行，每行两个整数 $r,c$（$0\le r<H$，$0\le c<W$）。

## 输出格式

共 $Q$ 行，每行三个整数 $x\ y\ d^2$；若不存在陆地，输出 `-1 -1 -1`。

## 样例输入

```
5 5 2 3
10101
11111
11111
11111
11111
6
0 2
4 2
2 2
0 0
1 1
0 1
```

## 样例输出

```
0 1 4
0 1 148
0 1 40
0 1 4
0 1 9
0 1 0
```

## 样例说明

陆地只有 $(0,1)$ 与 $(0,3)$ 两格（`0` 为陆地），其余全是水。

- $(0,2)$：到 $(0,1)$ 与 $(0,3)$ 的平方距离都是 $2^2=4$，并列时取 $x$ 更小的 $(0,1)$。
- $(4,2)$：到两格的平方距离都是 $(3\cdot4)^2+2^2=148$，同样取 $(0,1)$。
- $(2,2)$：到两格都是 $(3\cdot2)^2+2^2=40$，取 $(0,1)$。
- $(0,1)$ 本身是陆地，输出 `0 1 0`。

## 数据范围

| 变量 | 范围 | 说明 |
| --- | --- | --- |
| $W$ | $1\le W\le 2500$ | 横向格子数 |
| $H$ | $1\le H\le 2500$ | 纵向格子数 |
| $DX$ | $1\le DX\le 10^4$ | 每格横向米数 |
| $DY$ | $1\le DY\le 10^4$ | 每格纵向米数 |
| $Q$ | $1\le Q\le 10^5$ | 询问次数 |

## 提示

- 距离是**精确的加权欧氏距离**，不是四邻域/八邻域的步数；用 BFS 或倒角距离（chamfer）都会得到错误答案。
- $W\cdot H$ 最大为 $6.25\times10^6$，逐询问扫描全图不可行。
- 平方距离最大不超过 $1.3\times10^{15}$，可以放在 64 位有符号整数里。
- 二维距离可以拆成「横向一遍 + 纵向一遍」，每一维是一个**下包络**问题。
